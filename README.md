# Что такое Pip? с чем его едят? и причем тут библиотеки
## by [@hidlow](https://t.me/hidlow)

**``Библиотека (Module/Package)``**

**это именованная совокупность программного кода, реализующая `определённый функционал`.**  
**В Python библиотеки позволяют использовать `готовые решения для типовых задач` (сетевые запросы, криптография, парсинг данных), что `избавляет` от необходимости писать низкоуровневую реализацию с нуля**

***

**``pip (Package Installer for Python)``**  
**``pip`` - это стандартная `система управления пакетами`.**  
**Она `автоматизирует` процесс поиска, скачивания и установки библиотек из `PyPI` или других репозиториев (например, GitHub).**

***

**``Python Package Index (PyPI)``**
**Это основной репозиторий `ПО для Python`, где хранятся `сотни тысяч` сторонних пакетов.**
**Когда говорят о библиотеках в пайтоне, чаще всего имеют в виду именно пакеты, опубликованные на `PyPI`.**

***
## Как устанавливать Библиотеки?
```bash
pip install <название библиотеки>
```
**Самый простой способ. он устанавливает библиотеку `самой последней версии`**

**

```bash
pip install <название библиотеки>==3.12.0
```
**Устанавливает библиотеку `определенной версии`. Нужно для того, чтобы была совместимость кода**

**

```bash
pip install -r requirements.txt
```
**Устанавливает зависимости из `.txt` файла.**  
**Нужно для того, чтобы за одну команду установить `сразу все` нужные зависимости для скрипта.**  
**Часто встречается в `GitHub-репозиториях`, вместо `requirements.txt` может быть другое название файла.**
